# Impact You Academy

Impact You Academy is a full-stack academy management platform built using the MERN stack. It streamlines student registration, attendance tracking, fee management, and course administration through a secure and responsive web application.

## Live Demo

https://impactyouacademy.com/

## Features

- Student registration and profile management
- Secure JWT authentication
- Role-based access control
- Course management
- Attendance tracking
- Fee management
- Razorpay payment integration
- Email notifications with Nodemailer
- Responsive user interface
- RESTful API architecture

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Nodemailer
- Razorpay

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/ImpactYouAcademy.git
```

Install dependencies:

```bash
cd client
npm install

cd ../server
npm install
```

Create a `.env` file in the server directory and configure the required environment variables.

Run the application:

Backend:
```bash
npm run dev
```

Frontend:
```bash
npm start
```
